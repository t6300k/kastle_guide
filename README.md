## 📖 가이드 구성 내용
- **머신러닝 (Tabular ML) 실습**: 리테일 일일 매출 예측 (Retail Daily Sales Forecast)
- **딥러닝 (Computer Vision DL) 실습**: 도로 주행 차량 7종 분류 (Vehicle 7-Class Image Classification)

## 💡 주요 기능
- 한국어 / 영어 전환 (KO / EN)
- 27개 실습 화면 고해상도 스크린샷 및 줌 모달
- 모바일/태블릿 반응형 레이아웃 및 단계별 목차(TOC) 내비게이션
